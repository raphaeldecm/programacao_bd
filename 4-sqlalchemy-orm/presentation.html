O que é ORM?

  • ORM = Object-Relational Mapping
  • Mapeia tabelas de banco de dados para classes Python
  • Trabalha com objetos ao invés de SQL direto
  • Aumenta produtividade e segurança

Vantagens da ORM

✓ Produtividade

Escreva código Python ao invés de SQL

✓ Segurança

Proteção contra SQL Injection

✓ Portabilidade

Mude de banco facilmente

✓ Manutenção

Código mais organizado

Organização do Projeto

database.py ← Conexão com banco

models.py ← Definição das tabelas

crud.py ← Operações CRUD

main.py ← Arquivo principal

Arquivo database.py

from sqlalchemy import create_engine
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker

engine = create_engine('sqlite:///meu_banco.db', echo=True)

Base = declarative_base()

SessionLocal = sessionmaker(bind=engine)

Definindo Modelos

class Produto(Base):
__tablename__ = 'produtos'

id = Column(Integer, primary_key=True)
nome = Column(String(100), nullable=False)
preco = Column(Float, nullable=False)

Cada classe = Uma tabela no banco

Principais Tipos de Dados

Integer → Números inteiros

String(n) → Texto com tamanho máximo

Float → Números decimais

Boolean → Verdadeiro/Falso

DateTime → Data e hora

Constraints (Restrições)

  • primary_key=True → Chave primária
  • unique=True → Valor único
  • nullable=False → Campo obrigatório
  • default=valor → Valor padrão
  • autoincrement=True → Auto-incremente

Criando as Tabelas

from database import engine, Base
from models import Produto

Base.metadata.create_all(engine)
print("Tabelas criadas!")

Session - Comunicação com Banco

A Session é a "conversa" entre seu código e o banco

session = SessionLocal()

# Fazer operações

session.commit() # Confirmar
session.close() # Fechar

CRUD - CREATE (Inserir)

produto = Produto(nome="Notebook", preco=2500.00)

session.add(produto)
session.commit()

CRUD - READ (Consultar)

session.query(Produto).all() → Todos

session.query(Produto).get(1) → Por ID

session.query(Produto).filter(...).first() → Com filtro

session.query(Produto).count() → Contar

CRUD - UPDATE (Atualizar)

produto = session.query(Produto).get(1)
produto.preco = 2300.00

session.commit()

CRUD - DELETE (Remover)

produto = session.query(Produto).get(2)

session.delete(produto)
session.commit()

Relacionamentos: One-to-Many

Um Cliente → Várias Compras

class Cliente(Base):
__tablename__ = 'clientes'
id = Column(Integer, primary_key=True)
compras = relationship("Compra")

class Compra(Base):
__tablename__ = 'compras'
cliente_id = Column(Integer, ForeignKey('clientes.id'))

Relacionamentos: Many-to-Many

Alunos ↔ Disciplinas (tabela intermediária)

aluno_disciplina = Table('aluno_disciplina', Base.metadata,
Column('aluno_id', Integer, ForeignKey('alunos.id')),
Column('disciplina_id', Integer, ForeignKey('disciplinas.id'))
)

✓ Boa Prática: Organização

  • Separe em arquivos: models, crud, database
  • Use pastas para grandes projetos
  • Um modelo por arquivo (opcional)
  • Importações organizadas

✓ Boa Prática: Session

session = SessionLocal()
try:
# suas operações
except Exception as e:
session.rollback()
finally:
session.close()
