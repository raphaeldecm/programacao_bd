# 📚 Programação com Acesso a Banco de Dados

Este repositório contém materiais didáticos, exemplos de código e exercícios para a disciplina de **Programação com Acesso a Banco de Dados** ministrada no **IFRN Campus Pau dos Ferros**.

## 🎯 Objetivos da Disciplina

- Compreender os conceitos fundamentais de banco de dados
- Aprender a integrar aplicações Python com sistemas de banco de dados
- Desenvolver habilidades em SQL e operações CRUD
- Praticar boas práticas de programação com banco de dados

## 🛠️ Tecnologias Utilizadas

- **Python 3.x** - Linguagem de programação principal
- **SQLite** - Sistema de banco de dados para exemplos iniciais
- **PostgreSQL** - Sistema de banco de dados relacional
- **sqlite3** - Biblioteca padrão do Python para SQLite

## 📁 Estrutura do Repositório

```text
programacao_bd/
├── 1-integracao/          # Módulo 1: Conceitos básicos de integração
│   ├── 1-bd.py           # Conexão com banco de dados
│   ├── 2-tabela.py       # Criação de tabelas
│   ├── 3-create_data.py  # Inserção de dados
│   ├── 4-list_data.py    # Consulta de dados
│   ├── 5-update_data.py  # Atualização de dados
│   └── 6-delete_data.py  # Exclusão de dados
├── 2-aplicacao-console/   # Módulo 2: Aplicação console interativa
│   ├── crud_simples.py   # Aplicação principal
│   ├── database.py       # Gerenciador do banco de dados
│   └── utils.py          # Utilitários e validações
├── .gitignore            # Arquivos ignorados pelo Git
└── README.md             # Este arquivo
```

### Pré-requisitos

- Python 3.6 ou superior instalado
- Editor de código (VS Code, PyCharm, etc.)

## 📝 Exercícios e Atividades

Os exercícios práticos serão disponibilizados durante as aulas e organizados por módulos. Cada aluno deve:

1. Estudar os exemplos fornecidos
2. Executar os códigos em seu ambiente local
3. Completar os exercícios propostos
4. Fazer commit das soluções em repositório próprio

## 🎓 Para os Alunos

### Dicas de Estudo

- Execute cada exemplo e observe o resultado
- Experimente modificar os códigos para entender melhor
- Pratique criando suas próprias consultas SQL
